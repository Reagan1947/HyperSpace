# HyperSpace 桌面端 IDE 式页面布局设计文档

## 1. 文档说明

本文档描述 HyperSpace 当前主工作区的页面结构、功能分区、视觉规范和交互规则，用于后续产品设计、前端实现与验收。

- 产品形态：macOS 风格本地优先桌面应用
- 技术形态：React + Tauri
- 信息架构：IDE 式多区域工作台
- 视觉基调：沿用原有暖灰、米白和紫色强调色
- 核心原则：内容优先、工具按需展开、多任务切换清晰、布局状态稳定

IDE 截图仅用于参考信息密度和区域组织，不采用其深色配色，也不复制代码编辑器的业务语义。

## 2. 设计目标

1. 在同一窗口中统一承载项目树、笔记编辑、文件预览、搜索、收藏、页面属性和 AI 辅助能力。
2. 通过页签和工具窗口支持多任务处理，同时避免主编辑区被永久占用。
3. 保持原有柔和、轻量的知识管理产品气质，不变成传统开发工具的深色高密度界面。
4. 保留现有本地数据读取、自动保存、笔记编辑、文件嵌入和收藏功能。
5. 允许用户收起、展开和调整辅助区域，适配不同窗口尺寸。

## 3. 页面结构总览

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ 窗口标题行：窗口按钮  HyperSpace                                      │
├──────────────────────────────────────────────────────────────────────────┤
│ 导航工具行：历史导航 / 面包屑 / 全局搜索 / 保存状态 / 新建页面          │
├────┬─────────────────┬─────────────────────────────────────────────┬────┤
│    │ Project 标题栏  │ 文档页签栏                                  │    │
│ 左 ├─────────────────┼─────────────────────────────────────────────┤ 右 │
│ 工 │                 │                                             │ 工 │
│ 具 │   项目导航树    │                主编辑区                     │ 具 │
│ 轨 │                 │                            ┌──────────────┐ │ 轨 │
│    │                 │                            │上下文辅助面板│ │    │
│    │                 │                            └──────────────┘ │    │
│    │                 ├─────────────────────────────────────────────┤    │
│    │                 │ 可展开的底部工具窗口                        │    │
│    │                 ├─────────────────────────────────────────────┤    │
│    │                 │ 搜索 / 最近访问 / 收藏 / 数据日志          │    │
├────┴─────────────────┴─────────────────────────────────────────────┴────┤
│ 状态栏：保存状态 / 工作空间 / 内容类型 / 编码                           │
└──────────────────────────────────────────────────────────────────────────┘
```

一级区域包括：

1. `WindowTitleBar`：窗口标题行和导航工具行
2. `LeftActivityRail`：Project、Search、Favorites
3. `ProjectSidebar`：工作空间项目树
4. `WorkspaceTabs`：打开内容的页签
5. `WorkspaceCanvas`：笔记编辑或文件预览
6. `RightActivityRail`：Info、Outline、AI
7. `ContextPanel`：右侧上下文辅助面板
8. `BottomToolWindow`：搜索、最近访问、收藏等结果
9. `StatusBar`：全局状态信息

## 4. 布局尺寸

### 4.1 一级区域尺寸

| 区域 | 默认尺寸 | 范围或行为 |
| --- | ---: | --- |
| 顶部完整区域 | 86 px | 固定高度 |
| 窗口标题行 | 34 px | 顶部区域第一行 |
| 导航工具行 | 48 px | 顶部区域第二行 |
| 左侧工具轨 | 40 px | 固定宽度 |
| 项目导航面板 | 316 px | 可在 240–480 px 范围拖拽 |
| 右侧工具轨 | 40 px | 固定宽度 |
| 文档页签栏 | 36 px | 固定高度 |
| 右侧上下文面板 | 300 px | 按需展开 |
| 底部工具窗口 | 176 px | 按需展开 |
| 底部工具标签栏 | 32 px | 始终显示 |
| 全局状态栏 | 32 px | 始终显示 |
| 主内容区 | 剩余空间 | 最小宽高均为 0，内部独立滚动 |

### 4.2 应用外壳网格

```css
.app-shell {
  --titlebar-height: 72px;
  --left-activity-rail-width: 25px;
  --activity-rail-width: 40px;
  --sidebar-width: 316px;
  --tabbar-height: 36px;
  --statusbar-height: 32px;

  display: grid;
  grid-template-columns:
    var(--left-activity-rail-width)
    var(--sidebar-width)
    minmax(0, 1fr)
    var(--activity-rail-width);
  grid-template-rows:
    var(--titlebar-height)
    minmax(0, 1fr)
    var(--statusbar-height);
  width: 100vw;
  height: 100vh;
  overflow: hidden;
}
```

项目面板收起时，第二列宽度切换为 `0px`；中央工作区自动获得释放的空间。

## 5. 顶部区域

### 5.1 窗口标题行

窗口标题行用于展示桌面窗口语义，不承载业务操作。

- Web 预览展示红、黄、绿三个模拟窗口按钮。
- Tauri 环境使用 macOS 原生窗口按钮，隐藏模拟按钮，避免重复。
- 标题在窗口按钮右侧左对齐，格式为 `HyperSpace - 当前页签名称`。
- 空白区域作为 Tauri 窗口拖拽区域。

### 5.2 导航工具行

工具行从左至右包括：

1. 后退、前进
2. 面包屑导航
3. 全局搜索框
4. 本地保存状态
5. 新建页面
6. 更多操作

面包屑格式：

```text
HyperSpace > 内容类型 > 当前标题
```

全局搜索框：

- 默认宽度不超过 330 px
- 聚焦时自动打开底部“全局搜索”工具窗口
- 支持匹配页面、文件夹和文件标题
- 快捷键提示为 `⌘ K`
- 输入变化时实时更新搜索结果

## 6. 左侧工作区

### 6.1 左侧工具轨

左侧工具轨提供三个入口：

| 入口 | 功能 | 激活行为 |
| --- | --- | --- |
| Project | 展开或收起项目导航面板 | 激活时使用 `#BEBEBE` 背景高亮，不显示左侧指示线 |
| Search | 打开底部全局搜索窗口 | 再次点击关闭 |
| Favorites | 打开底部收藏窗口 | 再次点击关闭 |

标签使用竖向排版，图标位于标签下方。每项高度为 104 px。

### 6.2 项目导航面板

面板标题栏包含 Project 标题、下拉入口和新建页面按钮。

项目树结构：

```text
HyperSpace
├── 工作空间
│   ├── 产品探索
│   ├── 调研资料
│   │   ├── 用户访谈汇总.pdf
│   │   └── 产品路线图.xlsx
│   └── 会议记录
└── 个人
    └── 灵感收集
```

交互规则：

- 文件夹支持展开和收起。
- 页面、文件夹和文件均可选中并在中央页签打开。
- 当前节点使用暖灰选中背景。
- Hover 时显示更多操作按钮。
- 每增加一层，增加 18 px 缩进。
- 面板右边缘提供 6 px 拖拽热区。
- 拖拽宽度限制为 240–480 px。

## 7. 中央工作区

### 7.1 文档页签

页签用于在多个页面和文件之间切换。

- 最小宽度：128 px
- 最大宽度：240 px
- 默认建议宽度：180 px
- 激活页签使用米白背景和顶部 2 px 紫色指示线
- 标题过长时单行省略
- Hover 或激活时显示关闭按钮
- 关闭当前页签后，激活最近打开的剩余页签
- 当全部页签关闭后显示空白工作区提示

点击项目树节点时，如果对应页签未打开，则追加新页签；已打开时直接切换。

### 7.2 主编辑区

主编辑区继续承载现有内容能力：

- 页面标题编辑
- 文本块和标题块编辑
- Callout 提示块
- 文件夹嵌入块
- 文件嵌入块
- 页面元数据和作者信息
- 文件夹或文件的空状态页面

阅读型内容最大宽度为 820 px，并在编辑区内水平居中。主内容区自身不触发应用级滚动，内容滚动由 `WorkspaceCanvas` 负责。

## 8. 右侧工作区

### 8.1 右侧工具轨

| 入口 | 对应面板 | 内容 |
| --- | --- | --- |
| Info | 页面信息 | 类型、更新时间、访问权限、收藏状态和动态 |
| Outline | 页面大纲 | 自动提取当前笔记中的标题块 |
| AI | AI 助手 | 总结、提取待办、寻找相关内容和对话入口 |

三个工具互斥。同一入口再次点击时关闭右侧面板；切换入口时保持面板宽度不变，只替换内容。

### 8.2 页面大纲

- 仅提取 `heading` 类型且内容非空的块。
- 每个大纲项展示标题图标、标题文字和顺序编号。
- 当前页面没有标题时显示空状态。
- 后续可扩展为点击后滚动到对应编辑块。

### 8.3 AI 助手

AI 面板提供以下快捷建议：

- 总结当前页面
- 提取待办事项
- 寻找相关内容
- 开始对话

当前阶段为界面入口，后续接入模型服务时应保留加载、生成、失败和取消状态。

## 9. 底部工具窗口

底部工具标签栏始终显示，包含：

- 搜索
- 最近访问
- 收藏
- 数据日志

其中搜索、最近访问和收藏已具备可展开工具窗口。

### 9.1 全局搜索

- 搜索框位于顶部导航工具行。
- 搜索结果展示图标、标题、内容类型和跳转箭头。
- 点击结果会打开或切换到对应页签。
- 没有关键词时展示搜索提示。
- 结果区域采用自适应多列网格，单项最小宽度为 240 px。

### 9.2 最近访问

展示工作空间内最近更新的前六个节点。当前实现使用数据顺序和 `updatedAt` 展示，后续应改为真实访问时间排序。

### 9.3 收藏

仅展示 `favorite` 为 `true` 的节点。点击收藏结果打开对应页签。

### 9.4 数据日志

当前保留工具标签入口，后续用于展示本地保存、同步和文件处理日志。

## 10. 状态栏

状态栏横跨窗口底部，展示：

- 保存状态指示点
- 保存状态文字
- 当前工作空间 `HyperSpace`
- 当前内容类型
- 编码 `UTF-8`

状态颜色：

| 状态 | 颜色语义 |
| --- | --- |
| 已保存 | 绿色 |
| 读取或保存中 | 金黄色 |
| 离线 | 暖红色 |

  -apple-system,

  "Segoe UI",
  "PingFang SC",
  "Microsoft YaHei",
  sans-serif;

- 窗口标题：12 px / 600
- 工具行和面包屑：12 px
- 项目树：14 px
- 页签：14 px
- 正文：15 px，行高 1.85
- 二级标题：21 px / 650
- 页面标题：34 px / 620
- 状态栏及工具标签：11–12 px

### 11.3 边框、圆角和阴影

- 一级区域通过 1 px 暖灰分隔线区分。
- 常规控件圆角为 4–7 px。
- 卡片和内容块圆角为 8–10 px。
- 固定面板不使用明显阴影。
- 窄窗口下的覆盖式面板可使用轻量暖灰阴影。

## 12. 状态与数据模型

页面外壳应维护以下 UI 状态：

```ts
type RightTool = "info" | "outline" | "ai" | null;
type BottomTool = "search" | "recent" | "favorites" | null;

interface ShellState {
  projectOpen: boolean;
  sidebarWidth: number;
  rightTool: RightTool;
  bottomTool: BottomTool;
  openTabIds: string[];
  query: string;
}
```

工作空间业务数据仍由 `WorkspaceState` 管理，布局状态不应写入笔记内容。后续可将面板宽度和开关偏好单独持久化。

## 13. 响应式规则

| 窗口宽度 | 布局行为 |
| --- | --- |
| `≥ 1200 px` | 展示完整 IDE 工作台，可同时打开左右及底部工具窗口 |
| `901–1199 px` | 保持项目面板；右侧面板覆盖显示，不压缩主编辑区 |
| `721–900 px` | 项目面板默认使用紧凑宽度，右侧面板覆盖显示 |
| `≤ 720 px` | 项目面板改为左侧抽屉；状态栏隐藏次要信息 |

推荐最小窗口尺寸为 `720 × 520 px`。Tauri 当前可根据实际桌面体验设置更高的最小尺寸。

## 14. 可访问性

- 工具轨、页签栏和底部工具栏使用导航语义。
- 页签使用 `tablist`、`tab` 和 `tabpanel`。
- 项目树使用 `tree` 语义，并支持键盘 Enter 和 Space 打开。
- 所有纯图标按钮提供中文 `aria-label`。
- 键盘焦点使用 2 px 紫色焦点框。
- 关闭按钮和工具按钮的点击热区不小于 24 × 24 px。
- 文字和背景对比度应达到 WCAG AA。
- 尊重系统的减少动态效果设置。

## 15. 功能验收标准

1. 页面包含顶部双层导航、左右工具轨、项目面板、页签、编辑区、底部工具栏和状态栏。
2. 项目面板可展开、收起，并可在 240–480 px 范围内拖拽。
3. 点击项目树节点会创建或切换页签，不重复打开相同页签。
4. 页签支持切换和关闭，全部关闭后显示空状态。
5. 顶部搜索输入会打开底部搜索工具窗口并实时过滤节点。
6. 搜索、最近访问和收藏结果可跳转到对应页面。
7. 页面大纲能提取当前页面所有非空标题块。
8. Info、Outline 和 AI 面板互斥切换，并能独立关闭。
9. 主编辑区保留文本编辑、标题编辑、文件夹嵌入和文件嵌入能力。
10. 数据修改后自动写入本地存储，并正确展示保存、保存中和离线状态。
11. 在 1280 × 720 视口下，应用外壳不产生横向或纵向页面溢出。
12. 暖灰、米白和紫色设计 Token 与本文档一致，不采用 IDE 参考图的深色配色。
13. TypeScript 与 Vite 生产构建通过，浏览器控制台无错误。

## 16. 后续扩展建议

- 为后退、前进补充真实访问历史栈。
- 为大纲项增加滚动定位和当前标题高亮。
- 为页签增加拖拽排序、未保存状态和固定页签。
- 将最近访问改为真实访问时间排序。
- 为数据日志接入本地保存和同步事件。
- 为 AI 助手接入流式输出、停止生成和引用来源。
- 将侧栏宽度、打开工具窗口和页签列表作为独立 UI 偏好持久化。
- 增加命令面板，实现 `⌘ K` 全键盘操作。
