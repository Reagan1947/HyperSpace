# CR-02 文件树功能需求文档

## 1. 文档说明

本文档根据 HyperSpace 当前文件树实现反向整理，作为产品行为基线、测试依据和后续迭代输入。

- 变更编号：CR-02
- 功能范围：Project 侧边栏中的工作空间文件树
- 适用客户端：Web 预览与 Tauri 桌面端
- 节点类型：页面、文件夹、文件
- 当前状态：已实现

本文只描述已经落地的行为。尚未实现的能力在“范围外与后续项”中单独列出，不作为本期验收条件。

## 2. 背景与目标

用户需要在一个树形导航中同时组织页面、文件夹和本地文件，并通过直接操作完成内容定位、层级调整和顺序维护。

本功能目标如下：

1. 页面、文件夹和文件在同一棵树中展示。
2. 页面与文件夹均可承载子节点，文件始终为叶子节点。
3. 支持新建、选择、展开、重命名、删除和拖拽移动。
4. 拖拽时明确区分“同级排序”“移入容器”和“提升层级”。
5. 所有结构变化写回工作空间状态并自动保存到本地。
6. 在桌面 WebView 中不依赖不稳定的 HTML5 原生拖拽。

## 3. 概念定义

| 概念 | 定义 |
| --- | --- |
| 根目录 | `parentId = null` 的顶层工作空间位置 |
| 容器节点 | 可以拥有子节点的页面或文件夹 |
| 叶子节点 | 不能拥有子节点的文件 |
| 同级节点 | `parentId` 相同的一组节点 |
| 树深度 | 节点相对根目录的嵌套层数，根节点深度为 0 |
| 边界落点 | 位于某节点上方或下方的插入位置 |
| 内部落点 | 位于页面或文件夹内部末尾的插入位置 |
| 提升层级 | 将节点从当前父节点移出，成为某个祖先节点的同级项 |

## 4. 数据与层级规则

### 4.1 节点类型

| 类型 | 可包含子节点 | 默认图标 | 打开行为 |
| --- | --- | --- | --- |
| 页面 `page` | 是 | 页面图标 | 在中央工作区打开页面页签 |
| 文件夹 `folder` | 是 | 文件夹图标 | 在中央工作区打开文件夹视图 |
| 文件 `file` | 否 | 按文件类型显示 | 在中央工作区打开文件视图 |

补充规则：

- XLSX 文件使用表格图标，其他文件使用通用文件图标。
- 页面和文件夹即使暂时没有子节点，也必须保留成为父节点的能力。
- 只有实际存在子节点时才显示展开/折叠箭头。
- 每增加一层，视觉缩进增加 18 px。
- 节点顺序由同一父节点下各节点在工作空间数组中的相对顺序决定。

### 4.2 工作空间根节点

- 文件树顶部展示固定工作空间节点 `HyperSpace`。
- 点击 `HyperSpace` 可整体展开或收起项目树。
- `HyperSpace` 不是业务数据节点，不参与重命名、删除或普通节点拖拽。

## 5. 基础交互需求

### 5.1 展示与选择

1. 文件树占满 Project 面板剩余高度，并跟随面板尺寸变化。
2. 当前节点显示选中背景；获得键盘焦点时显示焦点边框。
3. 单击节点后：
   - 更新当前选中节点；
   - 若对应页签尚未打开，则新增页签；
   - 若页签已经打开，则切换到该页签。
4. 当前仅支持单选，焦点移动时选中状态跟随焦点。
5. 节点标题过长时单行省略，悬停可通过原生标题提示查看完整名称。

### 5.2 展开与收起

- 含子节点的页面和文件夹显示展开箭头。
- 点击箭头只切换展开状态，不触发节点打开。
- 文件树初始默认展开。
- 没有子节点的页面或文件夹不显示空箭头。

### 5.3 新建节点

支持新建页面和新建文件夹。

| 入口 | 当前选中/操作节点 | 新节点位置 |
| --- | --- | --- |
| Project 标题栏“+” | 文件夹 | 该文件夹下 |
| Project 标题栏“+” | 页面或文件 | 与当前节点同级 |
| 顶部工具栏“新建页面” | 文件夹 | 该文件夹下 |
| 顶部工具栏“新建页面” | 页面或文件 | 与当前节点同级 |
| 节点菜单“新建页面/文件夹” | 页面或文件夹 | 该节点下 |
| 节点菜单“新建页面/文件夹” | 文件 | 与该文件同级 |

新建后的行为：

- 页面默认标题为“未命名页面”，默认图标为 `◇`。
- 文件夹默认标题为“新建文件夹”。
- 新节点成为当前选中节点并新增打开页签。
- 新页面初始化一个空文本块。
- 更新时间标记为“刚刚”。

### 5.4 重命名

- Hover 节点后显示“更多操作”按钮。
- 通过节点菜单“重命名”或选中节点后按 `F2` 进入编辑状态。
- 编辑框自动聚焦并全选原名称。
- 按 `Enter` 或输入框失焦时提交非空名称。
- 按 `Escape` 取消本次修改。
- 纯空白名称不保存。
- 保存成功后节点更新时间更新为“刚刚”。

### 5.5 删除

- 节点菜单提供删除入口，危险操作使用红色文字。
- 删除前显示确认对话框并列出待删除节点名称。
- 删除页面或文件夹时，同时递归删除其全部后代节点。
- 同步删除被删除页面对应的内容块数据。
- 若当前选中节点被删除，自动选择剩余节点中的第一个节点。
- 若删除后工作空间为空，自动创建一个根级“未命名页面”及空文本块。
- 已打开页签同步移除被删除节点；工作空间被清空时保留自动创建的兜底页面页签。

## 6. 拖拽移动与排序需求

### 6.1 启动条件

- 用户在节点行的非按钮、非输入框、非菜单区域按下主指针并移动至少 5 px 后开始拖拽。
- 拖拽支持鼠标及 Pointer Events 能覆盖的其他指针设备。
- 开始拖拽后禁止文字选中，光标切换为抓取状态。
- 被拖节点降低透明度，并显示跟随指针的浮动预览。
- 单纯点击且移动距离不足 5 px 时仍按普通节点点击处理。

### 6.2 纵向落点区域

每个节点行按纵向位置划分落点：

| 指针位置 | 页面/文件夹 | 文件 |
| --- | --- | --- |
| 行高顶部 28% | 插入到节点上方 | 插入到文件上方 |
| 行高中部 44% | 移入容器末尾 | 按上下半区解析为上方或下方 |
| 行高底部 28% | 插入到节点下方 | 插入到文件下方 |

规则说明：

- 文件不能接收内部落点。
- 移入页面或文件夹时，新节点放在其全部现有子节点之后。
- 拖到树内没有具体节点的空白区域时，移动到根目录末尾。

### 6.3 横向层级判断

边界落点需要同时根据指针横向位置确定目标深度。

1. 指示线起点与最终目标深度一致，每层相差 18 px。
2. 指示线保持当前子级缩进时，表示在当前父节点内排序。
3. 指针向左移动时，指示线逐级变长，表示将节点提升到更高层级。
4. 在展开文件夹最后一个子节点下方：
   - 短线表示放入该文件夹末尾；
   - 向左延伸的长线表示放在该文件夹下方，并与文件夹同级。
5. 在展开文件夹第一个子节点上方采用对称规则。
6. 只有位于某层的首个或末个子节点边界时，才允许把落点提升到该父层；非边缘子节点不能通过横向移动跨过其他兄弟节点。
7. 多层嵌套中，如果每一层均满足首/末边界条件，可连续提升多个层级。

示例：

```text
文件夹 A
├── 页面 A1
└── 文件 A2
    ───────── 短线：仍在文件夹 A 内，放到 A2 下方
────────────── 长线：移出文件夹 A，放到文件夹 A 下方
```

### 6.4 拖拽反馈

| 状态 | 视觉反馈 |
| --- | --- |
| 正在拖动源节点 | 源节点透明度降低 |
| 插入上方/下方 | 显示 2 px 紫色插入线 |
| 不同目标深度 | 插入线起点随深度变化，越高层线越长 |
| 移入页面/文件夹 | 目标行显示紫色边框与浅紫背景 |
| 移到根目录末尾 | 树区域底部显示紫色指示线 |
| 浮动预览 | 显示节点标题及“移入…”或“放到…上方/下方”文字 |
| 无效落点 | 不显示有效插入反馈，松手不改变数据 |

插入线横向变化使用短过渡动画，避免层级提示跳变过于生硬。

### 6.5 安全约束

- 节点不能拖入自身。
- 节点不能拖入自己的任意后代，避免形成循环结构。
- 文件不能作为父节点。
- 无有效落点、指针取消或组件卸载时不执行移动。
- 拖拽完成后的短时间内抑制点击事件，避免松手时误打开节点。

### 6.6 排序结果

- 移动后更新节点的 `parentId`。
- 移动节点在目标父节点的兄弟列表中插入到指定位置。
- 同一父节点内排序时，需要扣除移动节点原位置对插入索引造成的偏移。
- 移动节点更新时间更新为“刚刚”。
- 节点的后代关系保持不变，移动容器时其整棵子树随之移动。

## 7. 本地保存需求

- 所有新建、重命名、删除、移动和排序操作均更新统一的 `WorkspaceState`。
- 状态变化后延迟 500 ms 自动保存，连续变化应合并保存。
- Web 环境写入 `localStorage` 的 `hyperspace.workspace.v1`。
- Tauri 环境通过 `save_workspace` 命令写入本地持久化存储。
- 保存失败时界面切换为离线状态，不阻塞用户继续操作。
- 启动时优先加载已保存工作空间；读取失败时回退到初始数据。

## 8. 验收标准

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| AC-01 | 从页面菜单新建页面 | 新页面成为该页面的子页面并显示为下一层 |
| AC-02 | 从文件菜单新建文件夹 | 新文件夹与该文件同级 |
| AC-03 | 拖文件到文件夹中部 | 文件移动到文件夹末尾，目标行高亮 |
| AC-04 | 拖页面到另一页面中部 | 页面成为目标页面的最后一个子页面 |
| AC-05 | 拖节点到同级节点上方 | 节点移动到该节点之前，显示上方插入线 |
| AC-06 | 拖节点到同级节点下方 | 节点移动到该节点之后，显示下方插入线 |
| AC-07 | 拖到最后子项下方并保持缩进 | 节点留在目标文件夹内并排在末尾，显示短线 |
| AC-08 | 在 AC-07 位置向左移动一级 | 节点移出文件夹并排在文件夹之后，显示长线 |
| AC-09 | 从多层最后子项继续向左 | 满足边界条件时逐层提升，线长同步变化 |
| AC-10 | 在非最后子项下方向左 | 不跨越剩余兄弟节点提升层级 |
| AC-11 | 尝试拖入自身或后代 | 不显示有效落点，树结构不变化 |
| AC-12 | 拖到文件行中部 | 解析为文件上方或下方，不成为文件子节点 |
| AC-13 | 拖到树空白区域 | 节点移动到根目录末尾 |
| AC-14 | 拖拽后刷新应用 | 层级和顺序保持不变 |
| AC-15 | 删除包含后代的页面/文件夹 | 确认后递归删除节点、内容块和相关页签 |

## 9. 非功能要求

- 拖拽必须在 Tauri WebView 与主流 Chromium Web 环境中行为一致。
- 树高度变化时应自动重新计算可视区域。
- 拖拽事件监听器必须在完成、取消和组件卸载时清理。
- 拖拽预览不得拦截指针命中检测。
- 节点菜单、重命名输入框和展开按钮不得误触发拖拽。
- 树应保留 `tree`、`treeitem`、`menu`、`menuitem` 等可访问性语义。

## 10. 范围外与后续项

以下能力当前未实现：

- 多节点选择与批量拖拽；
- 键盘完成拖拽排序；
- 拖到折叠容器后自动延时展开；
- 拖到可视区边缘自动滚动；
- 撤销、重做和移动历史；
- 跨工作空间拖拽；
- 外部操作系统文件直接拖入树；
- 服务端协同、冲突合并和权限校验；
- 同名节点检查及命名规则限制。
