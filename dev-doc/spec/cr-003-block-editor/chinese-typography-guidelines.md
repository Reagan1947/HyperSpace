# HyperSpace 中文排版规范

## 目标

本规范用于 HyperSpace 的桌面端笔记编辑器，优先保证简体中文长文的可读性，同时兼顾中英文、数字和代码混排。

编辑器采用网页阅读中常见的“段间留白”方式区分段落，不使用首行缩进。两种段落区分方式不应同时使用。

## 排版基线

| 元素 | 字号 | 行高 | 段前 | 段后 | 字重 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 正文 | 16px | 1.75（28px） | 0 | 10px | 400 |
| 一级标题 | 28px | 1.35 | 28px | 10px | 680 |
| 二级标题 | 22px | 1.4 | 24px | 8px | 650 |
| 三级标题 | 18px | 1.5 | 18px | 6px | 640 |
| 代码 | 13px | 1.6（20.8px） | 按代码块样式 | 按代码块样式 | 400 |

正文颜色使用 `#333336`，交互重点色使用 `#0071e3`。次要信息沿用应用的弱化文字颜色。

## 文字列宽

- 实际正文内容最大宽度为 `700px`。
- BlockNote 左侧为块操作菜单保留 `46px`，所以编辑器容器最大宽度为 `746px`。
- 以 16px 正文计算，一行约容纳 40–44 个中文字符，适合桌面端持续阅读和编辑。
- 窗口变窄时使用流式宽度，不产生横向滚动。

## 中文排版规则

### 字距

中文正文保持密排，`letter-spacing: 0`。不通过扩大字距制造留白；视觉节奏由行距和段距控制。短标题如有特殊视觉需求，字距调整也应保持克制，但当前编辑器标题统一使用 `0`。

### 行距

正文使用 `1.75`，处于中文屏幕阅读常用的 `1.5–1.8` 范围内。标题字号较大，分别使用 `1.35–1.5` 的紧凑行高，保持标题自身的聚合感。

### 段落

- 正文不设置 `text-indent`。
- 每个回车产生的新正文块在块后保留 `10px` 间距，形成清晰但不过度松散的段落节奏。
- 标题使用更明显的段前间距和较小的段后间距，使标题与其后内容形成一组。
- 列表的连续条目仅保留 `2px` 间距，不套用正文段距，避免列表被拆散。
- BlockNote 默认给标题内容增加的 `18px` 上内边距必须被覆盖，标题的垂直间距只由本规范中的段前、段后值控制，避免双重叠加。

### 换行与中英文混排

编辑器使用以下规则：

```css
line-break: strict;
word-break: normal;
overflow-wrap: break-word;
```

`line-break: strict` 尽量遵循中文标点的行首、行尾禁则；`word-break: normal` 避免无条件拆分西文单词；超长链接或连续字符串仍可通过 `overflow-wrap` 换行。

### 对齐方式

编辑状态默认左对齐，不强制两端对齐。这样可以避免浏览器为了填满行宽而不均匀地拉伸字符和标点间距，也能保持光标定位稳定。

## 字体回退

应用沿用系统字体栈：

```css
-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif
```

macOS 优先使用苹方，Windows 优先使用微软雅黑，并由系统西文字体处理拉丁字符和数字。

代码块使用独立的等宽字体回退顺序：

```css
"JetBrains Mono", "Maple Mono", "Maple Mono CN", "Maple Mono NF CN",
"SFMono-Regular", Consolas, "Liberation Mono", monospace
```

优先使用 JetBrains Mono 显示拉丁字符和代码符号；JetBrains Mono 缺少的中文字形由 Maple Mono 补充。若设备没有安装这两种字体，则继续退回系统等宽字体。代码内容使用紧凑的 `13px / 1.6`，通过缩小字体而不是挤压代码块留白来形成与正文的层级差异。

代码块使用浅色背景 `#f6f6f7`，不显示边框，内容内边距为上下 `18px`、左右 `16px`。语法高亮使用高亮主题的浅色 token，避免在浅色背景上继续显示为深色主题配色。

## 实现位置

排版规则集中定义在 `src/styles.css` 的 `.hyperspace-blocknote` 样式段中。正文内容由 BlockNote 管理，不应在单个 React 组件中重复写入字号、行高或段距。

## 验收标准

- 普通正文计算字号为 16px，计算行高为 28px。
- 连续正文块之间存在 10px 的可见段距，且没有首行缩进。
- 一级、二级、三级标题分别为 28px、22px、18px，并拥有独立行高。
- 实际正文内容在宽屏下不超过 700px。
- 中文正文没有额外字距。
- 中文标点不会在常规情况下出现在不合理的行首或行尾。
- 长英文单词和链接不会撑破编辑器宽度。
- 代码块背景为 `#f6f6f7` 且无边框，代码内容计算字号为 13px、行高约为 20.8px。
- 代码字体优先使用 JetBrains Mono，缺失的中文字形退回 Maple Mono。
